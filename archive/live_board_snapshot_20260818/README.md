# Live Board Snapshot 2026-08-18

This directory preserves source and small configuration files pulled from the live Ascend 310B board before returning the device.

Excluded intentionally: passwords, certificates, `.env` files, runtime logs, caches, Python bytecode, model artifacts (`.om`, `.onnx`, `.pt`, `.engine`), large datasets, and archives.

See `manifest.json` for copied paths, skipped paths, sizes, mtimes, and SHA-256 hashes.
